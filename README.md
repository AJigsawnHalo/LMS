# Library Management System
## Abstract
The Library Management System Using RFID and Barcode is a system that iterates on the common library system in issuing and returning books. This system adds a way to log anyone in and out of the library using an RFID tag. The same tag is used to by the user to checkout books out of the library.  The RFID tags are read by a RFID Reader attached to an Arduino Uno. The books are tracked   using a barcode attached to the books. This would be read by a barcode scanner. The system also includes a database using Microsoft Access to contain all this data. The system is packaged on to a single program built using Visual Basic .NET. This system would simplify and make the process of borrowing and returning books more efficient. The results the researchers have gotten show that the system is viable and effective.
